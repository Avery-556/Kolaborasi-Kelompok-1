Permisalan x = satu harga click clock
y = satu harga hiasan dinding

Permodelan 2x + y = 165.000
x + 2y = 195.000

Perhitungan Eliminasi = mengeliminasi nilai Y
2x + y = 165.000 (×2)
x + 2y = 195.000 (×1)

4x + 2y = 330.000
x + 2y = 195.000
________________ -
3x = 135.000
x = 45.000

Subtitusi = meng subtitusi kan nilai X
2x + y 165.000
2*45.000 + y = 165.000
y = 165.000 - 90.000
y = 75.000

Kesimpulan Jadi harga satuan click clock adalah 45.000.
Sedangkan harga satuan hiasan dinding adalah 75.000.
